# GIFs da documentação

Nenhum GIF foi incluído nesta versão da documentação.

GIFs devem ser usados apenas quando demonstrarem um fluxo real da aplicação, como:

- cadastro de uma conta;
- publicação de uma oportunidade pela ONG;
- inscrição de um voluntário;
- confirmação de um inscrito pela ONG.

## Orientações

- Grave o fluxo com a aplicação real em execução.
- Mantenha o arquivo curto e com tamanho reduzido.
- Não inclua dados reais de usuários, e-mails, CPF, CNPJ ou tokens.
- Nomeie o arquivo em minúsculas, sem espaços (por exemplo, `fluxo-inscricao.gif`).
- Faça o embed com caminho relativo a partir do documento que o utiliza.
