# Imagens da documentação

Este diretório reúne imagens **reais** do projeto, sem logotipos ou telas fictícias.

| Arquivo | Origem no projeto | Uso |
|---|---|---|
| `foto-sobre.avif` | `frontend/src/assets/foto-sobre.avif` | Página **Sobre** |
| `foto-comofunc.avif` | `frontend/src/assets/foto-comofunc.avif` | Página **Como Funciona** |

> Os arquivos foram copiados das pastas de assets do frontend para que a documentação não dependa de caminhos fora de `docs/`. O formato AVIF pode não ser renderizado por todos os visualizadores de Markdown; nesse caso, use o link direto para abrir a imagem.

## Como adicionar novas imagens

1. Use capturas reais da aplicação em execução ou imagens já presentes no repositório.
2. Prefira PNG ou JPEG para ampla compatibilidade em READMEs.
3. Nomeie os arquivos em minúsculas, sem espaços (por exemplo, `painel-ong.png`).
4. Atualize a tabela acima e os links nos documentos.
5. Não inclua dados pessoais, tokens, senhas ou informações sensíveis nas capturas.
